# 🌙 梦境漂流

乘一只纸船穿过 8 个梦境世界：收集光点、避开障碍，每个世界都有一条怪规则。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/13-dream-drift/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），无法保存时开始界面会给出提示。

## 玩法与关卡
8 个梦境：灯湖（新手）、糖果岸（侧风）、星海（星座组合加分）、水母林（漂移水母）、竹雾（浓雾，远处很晚才看见）、齿轮城（只留一个缺口的齿轮闸门 + 加速带）、书页海（翻页时左右反转）、晨光（规则混合、速度更快）。航程结束时光点达标进入下一个梦，撞 3 次失败；收集率 ≥ 60% 与无伤各加 1 星。

## 操作
**键盘 / 鼠标**
- A/D 或 ← → 转向，按住空格 / ↑ / W 冲刺（消耗梦能，收集光点回复），Esc 暂停

**手机触屏**：按住屏幕左侧 / 右侧转向，按住底部中间「冲刺」。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:13-dream-drift`），保存：解锁梦境、每个梦境的星级与最高光点数、累计光点。

## 数值调平
用机器人（每 0.2 秒决策一次，朝最近的安全光点转向，安全时冲刺）每个世界跑 6 次：最初星海太容易（星座加分）、齿轮城和终章几乎必死；把星海目标提到 45，闸门出现率降到 12% / 7%，终章降速并降低目标后，通过率从第 1 个世界的 6/6 逐步降到后段约 2–5/6。
