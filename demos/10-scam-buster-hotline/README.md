# ☎️ 反诈拖延热线 Scam Buster Hotline

反转视角的“呼叫中心”游戏：你是反诈志愿者，接听模拟诈骗电话，尽量拖住骗子，不泄露真实信息，并识别诈骗话术。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 每轮从“拖延 / 装傻 / 假装上钩 / 给假信息（有风险）”中选择回应，不同选择拖延的时间和消耗的骗子耐心不同
- “（照做）……”选项代表泄露真实信息，会扣分并计入泄露次数
- 挂断或骗子放弃后，勾选这通电话里出现的诈骗话术，答对加分、答错扣分

## 胜负条件
5 通电话后总分（拖延分钟数 + 识别加分）≥ 80 获胜；泄露 2 次即失败。
