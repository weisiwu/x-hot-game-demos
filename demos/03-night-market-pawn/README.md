# 🏮 夜市旧货摊 Night Market Pawn

经营夜市旧货摊：鉴定成色、比对失窃登记序列号、和顾客讨价还价，撑过 5 天。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- ±10/±50 调整出价，点“出价”。出价低于顾客心理底价会被还价并消耗耐心（重复出同样的价会额外扣耐心）
- “扫描成色”每天 3 次，显示真实成色与估值
- 序列号若出现在“失窃登记”列表里就是赃物：赃物便宜、转卖利润高，但打烊时有概率被查获罚款并增加关注度；拒收赃物会降低关注度
- 注意“只差一位”的序列号是无辜的

## 胜负条件
撑过 5 天并付得起每晚递增的摊位费即胜利；现金为负或关注度达到 3 即失败。
