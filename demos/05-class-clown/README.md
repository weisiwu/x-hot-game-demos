# 🏫 课堂捣蛋王

趁老师不注意溜出座位搞恶作剧，别被抓到，也别被班长告状。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/05-class-clown/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），能玩，但存档能否保留取决于浏览器，无法保存时开始界面会给出提示。

## 玩法与关卡
6 节课：语文 → 期末考。讲台型老师会写板书、虚晃一枪、快速回头；美术课是巡逻型老师（黄色扇形视野）；期末考两种模式交替。班长左顾右盼时在他附近乱跑会被举报。每节课恶作剧点组合不同，下课前全部完成过关，被抓 3 次失败，按被抓次数评星。

## 操作
**键盘 / 鼠标**
- WASD / 方向键移动，按住空格恶作剧，贴着课桌按住 Shift 趴下，Esc 暂停

**手机触屏**：画面左侧拖动摇杆移动；右下角「恶作剧」「趴下」两个按住式按钮。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:05-class-clown`），保存：解锁课程、每节课星级与最高分、累计恶作剧数。

## 数值调平
根据跑位距离估算：从黑板恶作剧点跑到最近可躲藏处约 0.7 秒，而“快速回头”只有 0.4 秒预警，因此把第 3、4 关的快速回头概率降到 18% / 22%。

## 原创说明
原作是多人非对称派对游戏；本 demo 是原创的单人潜行玩法（“一二三木头人”式节奏 + 躲藏 + 告密者），名称、角色、关卡均为原创。
