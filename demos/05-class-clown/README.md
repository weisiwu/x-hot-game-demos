# 🏫 课堂捣蛋王 Class Clown

趁老师背对全班写板书时溜出座位搞恶作剧，老师回头前要回到座位或趴在课桌边躲好。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- WASD / 方向键移动；走到 ⭐ 处按住空格进行恶作剧（进度会保留）
- 老师头顶出现 ❗ 表示马上转身（有时是虚晃一枪）
- 贴着课桌按住 Shift 趴下，可在老师看过来时躲藏
- 班长 👓 左顾右盼时，在他附近走动会被举报，老师立刻回头

## 胜负条件
下课（150 秒）前完成 5 个恶作剧获胜；被抓 3 次或下课时没做完即失败。按 R 重开。

## 原创说明
原作是多人非对称派对游戏；本 demo 是原创的单人潜行玩法（“一二三木头人”式节奏 + 躲藏 + 告密者），名称、角色、关卡均为原创。
