# 🧗 体力登顶 Stamina Summit

体力管理攀爬：点击岩点向上爬，每一步和每一秒悬挂都在消耗体力，只有平台能回体力，摔落会降低体力上限。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 点击绿色高亮（够得着）的岩点移动；点击平台可在平台上走动
- 灰色裂纹岩点抓住 1.2 秒后会碎（6 秒后重新长出）
- 🍎 恢复体力上限；高处会有阵风，提示出现时尽快到平台
- 按 R 重开（随机生成新山）

## 胜负条件
登上山顶 🚩 获胜；体力上限低于 25 失败。
