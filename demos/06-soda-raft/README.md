# 🥤 汽水木筏 Soda Raft

两只青蛙共乘一条木筏，用左右两个汽水喷口操控方向，逆流而上躲开石头和漂流木。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 左喷口 A、右喷口 L（推荐两人一人一边）；只喷一侧会转向，两侧同时喷才直行
- 单人：← / → 转向，↑ 双喷
- 汽水会耗尽，松开会慢慢回满；捡 🥤 立即补充
- 撞河岸、石头、漂流木会掉血

## 胜负条件
到达上游终点旗帜获胜；3 点生命耗尽失败。按 R 重开。
