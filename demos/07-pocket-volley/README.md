# 🏐 口袋排球 Pocket Volley

极简街机排球：移动、跳跃、扣球，先到 7 分获胜。可人机也可本地双人。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 左侧玩家：A/D 移动，W 跳跃，空中靠近球时按 S 扣球
- 按 2 切换本地双人，右侧用 ←→ 移动、↑ 跳、↓ 扣球
- 每边最多触球 3 次，超过判对方得分

## 胜负条件
先到 7 分获胜，按 R 再来一局。
