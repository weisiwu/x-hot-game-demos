# 🎟️ 刮刮大亨

从 $30 起步刮刮卡，升级幸运和自动刮卡机，赚到一百万（纯虚构游戏币）。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/04-scratch-tycoon/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），能玩，但存档能否保留取决于浏览器，无法保存时开始界面会给出提示。

## 玩法与关卡
长期增量游戏：5 种卡按累计收入解锁；🍀 让本卡奖金翻倍，💎 额外送 25 倍卡价；手刮的中奖额外 +25%。5 种升级（幸运、大刷子、自动刮卡机、提速、金色涂层）。里程碑 $100 → $1,000,000，达到百万时通关结算，之后可继续无尽或“转生”换取永久加成的幸运星。买不起最便宜的卡就算破产（失败结算，可领救济金继续）。

## 操作
**键盘 / 鼠标**
- 鼠标在卡面上按住来回刮；空格 = 再买一张当前卡种；Esc 暂停

**手机触屏**：手指在卡面上涂抹即可刮开；按钮在卡片旁边或下方。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:04-scratch-tycoon`），保存：金钱、所有升级、已刮卡片数、累计收入、里程碑、成就、幸运星，每 4 秒以及每次操作后自动保存。

## 数值调平
离线复刻公式模拟 30 次：起初早期 44 分钟才到 $1000、后期 3 分钟冲到百万，于是降低起步门槛、提高自动刮卡机价格并放慢速度；调整后中位约 23 分钟到百万、破产中位约 1 次。
