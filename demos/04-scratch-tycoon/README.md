# 🎟️ 刮刮大亨 Scratch Tycoon

刮刮卡增量游戏：用鼠标刮开涂层，3 个相同金额即中奖，用奖金升级幸运、刷子和自动刮卡机，赚到 $1,000,000。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 右侧选择卡种购买（铜/银/金/钻石/传奇，越贵奖金越高）
- 在卡面按住鼠标来回刮，刮开约 60% 自动结算；🍀 让本卡奖金翻倍
- 升级：幸运（提高中奖率）、大刷子、自动刮卡机（按当前卡种自动刮）、刮卡机提速
- 破产且没有自动刮卡机时会领到 $5 低保，不会卡死

## 胜负条件
现金达到 $1,000,000 即通关（全部为虚构游戏币）。
