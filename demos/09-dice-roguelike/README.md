# 🎲 骰运连连

掷骰凑牌型，“筹码 × 倍率”计分，买护符改造规则，连过 8 轮。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/09-dice-roguelike/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），能玩，但存档能否保留取决于浏览器，无法保存时开始界面会给出提示。

## 玩法与关卡
8 轮（第 3、6、8 轮为 Boss 轮：禁一、沉重、骰王），20 个护符（含稀有护符）与 3 种一次性符咒，普通/困难两档难度，通关后可继续无尽模式，有护符图鉴。

## 操作
**键盘 / 鼠标**
- 点击骰子或按 1–5 锁定，R 重掷，Enter 计分，Esc 暂停

**手机触屏**：全部为点击操作，手机可直接玩。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:09-dice-roguelike`），保存：每轮开始自动保存当前局（可继续）、通关/困难通关次数、最远轮次、无尽最远、护符图鉴。

## 数值调平
用机器人（保留最多的点数或顺子、按优先级买护符）各打 200/100 局：最初普通 51%、困难 36%，但几乎所有失败都集中在最后一轮；调整目标分后普通约 53%、困难约 33%，失败分散到第 6–8 轮。
