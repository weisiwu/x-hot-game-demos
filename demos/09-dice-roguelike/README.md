# 🎲 骰运连连 Dice Gambit

“筹码 × 倍率”计分的 roguelike 构筑：掷骰凑牌型，在商店买护符改造计分规则，连过 8 轮。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 点击骰子（或按 1–5）锁定，点“重掷”（或 R）重掷未锁定的骰子
- 点“计分出手”（或 Enter）按牌型计分：得分 = (牌型筹码 + 点数和) × 倍率
- 过关后进入商店，最多持有 5 个护符，可卖出换钱；剩余出手次数与存款利息会给额外奖励

## 胜负条件
8 轮全部在出手次数内达到目标分即胜利；某轮出手用完仍未达标即失败。

## 原创说明
使用骰子而非扑克牌，牌型、护符和数值全部原创；只借用“筹码 × 倍率”这一通用计分思路。
