# 🤖 机甲布阵 Mech Formation

布阵自走棋（auto-battler）：用能源部署和升级机甲，开战后自动战斗，击退 7 波敌军。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 右侧选择机甲类型，点击下半场格子部署；对同类机甲再点一次 = 升级（最高 3 星）
- 右键或“回收模式”出售机甲（返还 70%）
- 5 种机甲：重盾卫士、速射枪手、重炮（溅射）、突袭者（切后排）、维修机（治疗）

## 胜负条件
击退全部 7 波获胜（第 7 波有 Boss）；基地耐久归零失败。
