# ✨ 弹幕天堂 Mini

幸存者类：自动攻击、升级三选一，撑到 Boss 出现并击败它。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/08-bullet-heaven/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），能玩，但存档能否保留取决于浏览器，无法保存时开始界面会给出提示。

## 玩法与关卡
3 个关卡（星光草原 3 分钟、迷雾墓园 4 分钟、虚空深渊 5 分钟），敌人包括会吐弹的远程怪和幽灵；每 45 秒出现金色精英怪，击败掉落宝箱（免费再选一次强化）。5 种武器（魔弹、旋刃、冲击波、闪电链、火焰光环）与 6 种属性强化。结算获得星币，可购买 5 项永久强化（体魄、力量、敏捷、引力、学识）。

## 操作
**键盘 / 鼠标**
- WASD / 方向键移动，1/2/3 或点击选择升级卡，Esc 暂停

**手机触屏**：在画面任意位置按住拖动出现摇杆；升级卡片直接点。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:08-bullet-heaven`），保存：星币、永久强化等级、关卡解锁、每关最高分与通关次数、累计击杀。**已修复上一版 file:// 下存档问题**：改用框架统一存档，检测到浏览器不可写入时会在开始界面明确提示，并建议用本地 http 服务器访问。

## 数值调平
用风筝式机器人模拟：经验曲线从 5+4.5×等级 放宽到 4+2.6×等级（3 分钟约到 12–15 级），Boss 血量调为 350 / 900 / 2000；无局外成长时第 3 关撑不到 Boss，需要局外成长。
