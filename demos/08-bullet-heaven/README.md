# ✨ 弹幕天堂 Mini

幸存者类（Bullet Heaven）：自动攻击、捡经验升级三选一，撑过 3 分钟后击败大怪，还有局外永久成长。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- WASD / 方向键移动，武器自动攻击
- 升级时点击卡片或按 1/2/3 选择：魔弹、旋刃、冲击波、生命、移速、磁铁、力量
- 结算获得星币，开始界面按 1/2 购买永久生命/伤害（保存在浏览器 localStorage）

## 胜负条件
存活 3 分钟后出现大怪，击败即胜利；生命归零失败。
