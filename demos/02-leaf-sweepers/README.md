# 🍂 落叶清扫队

天黑前把公园的落叶扫干净，卖给堆肥站换钱升级，可本地双人合作。

## 怎么运行
推荐在仓库根目录运行 `python3 -m http.server 8000`，然后打开 http://localhost:8000/demos/02-leaf-sweepers/ （存档最可靠）。也可以直接双击 `index.html`（`file://`），能玩，但存档能否保留取决于浏览器，无法保存时开始界面会给出提示。

## 玩法与关卡
8 个公园：树木越来越多（树干挡路），后期会刮风让树上再掉叶子、出现减速水坑，清洁度目标 90% → 95%，时限 240 → 150 秒。金钱和 5 种升级（扫帚、落叶袋、跑鞋、扫地机器人、堆肥加工）跨关卡永久保留，过不去可以回前面的关卡赚钱再来。

## 操作
**键盘 / 鼠标**
- P1：WASD（单人时方向键也可以）
- P2：方向键（在菜单打开「双人模式」）
- 数字键 1–5 购买升级，Esc 暂停

**手机触屏**：单人时整个画面都是摇杆区；双人时左半屏是 P1 摇杆、右半屏是 P2 摇杆，可两人同时操作。升级按钮在画面下方。

右上角按钮：⏸ 暂停、🎵 背景音乐开关、🔊 静音、❓ 教程、🏠 返回目录（静音与音乐设置会记住）。首次开始会自动显示教程。

## 存档
使用浏览器 localStorage（键名 `xhgd:02-leaf-sweepers`），保存：解锁公园、星级、最佳用时、金钱、升级等级、双人模式开关、累计扫叶量。

## 数值调平
用贪心机器人（找最密落叶、满袋回站、卖完买最便宜的升级）加速模拟 8 关：早期升级太便宜导致第 1 关就基本买满，于是把升级价格提高到“全部满级约需 1.9 万”，堆肥加成减半，风力降到原来约 1/4；调整后机器人第 1 关用时约 169/240 秒，之后随升级逐关加快。
