# 🍂 落叶清扫队 Leaf Sweepers

合作 + 增量清洁：扫落叶 → 送到堆肥站卖钱 → 升级扫帚、袋子、跑鞋、买扫地机器人，把整个公园扫干净。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- P1：WASD 移动（移动时自动清扫光标圈内的落叶）
- 按 P：本地 2P 加入/离开，2P 用方向键；升级全队共享
- 数字键 1–5 或点击下方按钮购买升级
- 袋子满了要回到中央堆肥站，进站自动卖出

## 胜负条件
公园清洁度达到 95% 获胜，显示总用时。
