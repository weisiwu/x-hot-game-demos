# 🪡 草堆寻针 Haystack Hunt

在 7,000–18,000 根稻草里找一根针。按住鼠标拖动拨开稻草，看到银色的针后单击它。

## 怎么玩
直接用浏览器打开本目录下的 `index.html` 即可（无需构建、无需联网）。

- 按住左键拖动：拨开光标圈内的稻草（最上层先被拨走）
- 单击：在针的位置单击判定（针上压着的稻草 ≤1 根才算找到）
- 右侧商店：拨开的稻草每 40 根换 1 金币，可买更宽的耙子、更大力气、金属探测器（鼠标离针越近越红）、磁铁吹风

## 胜负条件
依次找到 3 个越来越大的草堆里的针即通关，记录每关用时。

只借用“大海捞针”这个俗语式玩法创意，稻草数量、升级系统、探测器与磁铁均为原创设计。
